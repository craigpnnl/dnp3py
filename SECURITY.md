## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's private
vulnerability reporting feature, not through a public issue, pull request,
or discussion.

To report a vulnerability:

1. Go to the repository's Security tab.
2. Select "Report a vulnerability".
3. This opens a private security advisory at
   https://github.com/craigpnnl/dnp3py/security/advisories/new

Please include:

- The affected version or commit.
- The affected component (for example the parser, the outstation, or the
  master).
- A description of the vulnerability.
- Reproduction steps or, where applicable, reproduction bytes.
- The impact.
